# OGxLuxuries' Claude plugins

One marketplace for my Claude Code / Desktop plugins.

To install them all:
```bash
claude plugin marketplace add OGxLuxuries/claude-plugins
claude plugin install codex-subagent@og
claude plugin install zen-garden@og
```



| Plugin | What it does | Source |
| --- | --- | --- |
| `codex-subagent` | Claude delegates bounded subtasks to OpenAI Codex (`codex exec`), shown live in a Terminal tab, then verifies the result. | [OGxLuxuries/codex-run](https://github.com/OGxLuxuries/codex-run) |
| `zen-garden` | [THEME] A calm Japanese-garden look for the Claude desktop app: shoji paper, moss green, bamboo in the wind, a koi pond. | [`plugins/zen-garden`](plugins/zen-garden) |

Auto-updat: run `claude` or open claude app, open `/plugin` → Marketplaces → `og`, and enable it.
